# 项目阅读指南

这是一门小型静态类型语言的编译器：输入 `.toy` 源文件，输出 Linux x86-64 ELF。词法和语法分析使用 Flex/Bison；AST、语义检查、LLVM IR 生成、工具链驱动及运行时由本项目实现。

## 当前范围

已实现整数、浮点、布尔、ASCII 字符串、函数、递归、控制流、一维定长数组、结构体和有序 `parallel map`。只选择确定性并行扩展，不提供源语言锁、Future、嵌套并行或任意动态转换。

公开算法目录目前没有 suite；自声明功能及内部回归通过不能等同课程最终验收。内存采用进程生命周期区域，临时值不会及时回收；目前不做自定义优化。详细限制见 [架构文档](architecture.md)。

## 先认识这些术语

- **token**：扫描器识别的词法单元，例如名称、数字、加号。
- **AST**：抽象语法树，记录“这是乘法，其左右子表达式是什么”。
- **sema / Checked**：语义检查及其结果，回答名字绑定到谁、表达式是什么类型。
- **LLVM IR**：交给工具链生成机器码的中间代码，可以导出为 `.ll` 阅读。
- **ABI**：生成代码和运行时交换参数、结果的约定；此项目统一使用 i64 表示。
- **runtime**：随产物链接的支持库，程序运行时负责输入输出、检查和并行调度。
