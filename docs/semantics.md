# 首版静态语义与运行时约定

本文记录当前已实现规则，取代早期设计笔记中“与 C++ 一致”和动态扩容等暂定描述。

## 类型与程序组织

- `.toy` 文件共同组成一个程序；顶层只允许函数与结构体；函数只允许一个定义，结构体名称不得重复或与函数冲突。非递归调用及结构体引用仍不受声明顺序影响。
- 入口为 `def main() -> int` 或 `def main() -> void`，没有参数；整数返回值的低 8 位作为进程状态。
- 支持 `int`（有符号 64 位）、`float`（binary64 有限浮点值）、`bool`、ASCII `string`、具名结构体和一维数组 `T[]`；`void` 只用作函数返回类型。不支持函数值、嵌套数组或递归结构体布局。
- 类型在编译期确定。仅在算术和赋值位置允许 `int → float`，详细范围见下节。`bool` 不参与算术，也不隐式或显式转换为 `int`。不允许任意值根据运行时需要转换类型。
- 显式转换允许同类型转换、`string(int)`、`string(bool)`、`int(string)`、`float(int)`、`int(float)`、`string(float)`、`float(string)`。整数字符串必须完整匹配 `-?[0-9]+` 并在 int64 范围内；不接受空白、加号或尾随字符。

## 浮点与类型提升

`float` 保存 binary64 有限值，支持 `1.5`、`1e3`、`1.25e-2`；小数点两侧必须有数字（不接受 `.5`、`1.`）。字面量不能溢出，不能小到转换器无法表示；支持可表示的次正规数。算术结果可下溢为零，产生非有限值则报错，不提供 NaN/Infinity。

`+ - * /` 允许混合 int/float，统一提升为 float；`%` 只允许 int。一元正负号保留操作数类型。变量初始化、赋值、复合值槽位赋值和有 float 元素上下文的数组字面量/并行 yield，允许 int 提升为 float。整型数组整体不能隐式变成浮点数组。

函数标量实参、返回值、比较、相等和原型匹配仍要求精确类型；需要时显式转换，不允许 bool 与任何数值互转。没有浮点布尔真值规则。`int(float)` 向零截断，结果必须落在 int64 范围内。

浮点数遵循二进制舍入，整数提升可能损失精度；相等比较为数值精确比较，`-0.0 == 0.0` 为 true。浮点除零和非有限算术结果报错。`string(float)` 使用与 locale 无关的最短可往返十进制表示，`float(string)` 要求完整有限数值，不接受空白、前导加号或尾随字符。

## 函数原型与递归

函数原型以分号结尾，只声明签名，不含函数体：

```text
def fact(n: int) -> int;
def fact(n: int) -> int {
    if (n <= 1) { return 1; }
    return n * fact(n - 1);
}
```

直接自递归和间接互递归中的每个函数，都必须在自己的定义前有显式原型。编译器分析完整调用图来识别递归环；普通函数调用递归函数，不会因此被视作递归。该规则比 C 的直接自递归更严格，是本语言的明确要求。

原型和定义的返回类型、参数数量、各参数类型必须完全一致；参数名称可以不同。允许重复的一致原型，但只允许一个定义。仅声明而没有定义的函数在编译期报错；首版不提供 extern 或分别链接的源语言模块。

多文件按命令行输入顺序、文件内声明顺序判断“在定义前”。写在函数体后面的原型不能补救先前的递归定义。该要求仅针对递归函数，不改变普通非递归前向调用规则。

## 变量、控制流与求值

所有源语言变量均为可变 `var`。同一作用域不得重名，内层可以遮蔽外层；局部变量可以暂不初始化，但读取及通过它写字段/元素前必须已初始化。初始化分析合并所有可继续执行的分支；循环体内赋值不保证循环外初始化。声明的初始化表达式在新绑定进入作用域前求值。

非 void 函数要求所有可达分支返回正确类型。当前检查保守地不证明无限循环或恒真条件；应使用显式 `return`。并行体不允许 `return`，最后必须 `yield`。

表达式、调用实参、数组元素从左到右求值；`&&`、`||` 短路。赋值先求目标位置（并检查边界），再求右值。C 风格 `for` 及 `while` 正常运行；`for (var x:T in array)` 进入时求数组一次。

整数加减乘、取负、除零以及 `INT64_MIN / -1`、`INT64_MIN % -1` 均检查并报告运行时错误。除法向零截断，余数与被除数同号。允许字面量 `-9223372036854775808`；超过 int64 范围的其他字面量在编译期拒绝。

## 数组、结构体与内存

数组创建时确定长度，之后不变。支持 `[expr, ...]`、`new T[length]`、索引读写及 `len(array)`。空字面量需要声明、参数或返回类型提供元素类型。新数组元素按类型初始化为 `0`、`0.0`、`false`、空字符串、空数组或字段递归默认初始化的结构体。

结构体按声明字段顺序构造，例如 `Pair(1, "a")`。数组与结构体在赋值、初始化、传参、返回和并行结果存储时深复制；字符串不可修改，可以安全共享。字段/索引赋值必须根植于已初始化的变量，不能修改临时值。

运行时使用进程生命周期的分线程内存区域，保存字符串和复合值，进程退出时统一释放；后台线程创建的返回值在主线程使用时仍有效。当前不回收中间临时值，长时间大量分配的程序会占用较多内存，这是首版的性能限制。

## 内置接口

| 接口 | 行为 |
| --- | --- |
| `read_char() -> int` | ASCII 编码或 EOF `-1`；非 ASCII/输入错误报错 |
| `print(string) -> void` | 原样输出，包括 NUL，不追加换行，检测输出错误 |
| `concat(string, string) -> string` | 不修改参数 |
| `substr(string, int, int) -> string` | 半开区间，检查 `0 <= start <= end <= len` |
| `len(string或array) -> int` | 字节数或元素数 |
| 字符串 `==`、`!=` | 按完整内容比较 |
| `range(end)`、`range(start,end[,step]) -> int[]` | 半开区间，支持负步长，零步长报错；遇 int64 下一步溢出时结束 |

错误写 stderr 并返回非零状态；源程序 stdout 只包含程序输出。

## 确定性并行

`parallel map (i, x in array) { statements; yield expr; }` 输入求值一次，等待全部迭代后返回按下标排列的新数组。空输入得到类型正确的空结果。

输入元素、下标及外部捕获绑定在并行体中只读；不引入不可变声明语法。可以复制捕获值到可变局部变量。函数参数采用深复制，因此辅助函数修改自己的参数不会修改调用方。编译器对调用图求副作用闭包，拒绝直接/间接 I/O 和嵌套并行；未声明或不支持的调用也不能通过类型检查。

运行时自行用 `std::thread`、互斥锁、条件变量和任务队列实现固定线程池；工作者领取下一个下标，各自写独立结果槽。`LAB_THREADS` 默认 `1`，接受 `1..1024` 的十进制正整数；非法值即使输入为空也报错。不提供源语言锁、任务句柄或 Future。

所有已调度任务结束后统一传播最小输入下标处的错误，因此 1/2/4 个线程的结果和错误选择相同。资源耗尽、线程创建失败等基础设施错误无法保证与串行消耗相同的资源或输出。
