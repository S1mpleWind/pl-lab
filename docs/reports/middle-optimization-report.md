# 中端优化实验报告

日期为 2026-11-09，实验分支为 `experiment/middle-optimizations`。本实验依据课程第 4.2 节，在 LLVM IR 上实现跨基本块分析与保持程序语义的优化。

## 1. 实现结构

语义检查完成后，优化器将本项目生成的 LLVM IR 解析成显式的函数、基本块和指令结构，记录操作数、结果与控制流边。通过 `-O1` 启用，`-O0` 提供行为对照。主要代码位于 `src/ir/optimize.cpp`。

常量传播、分支裁剪、不可达块删除、死代码消除和副作用分析均由项目自行实现。LLVM 的 verify pass 负责优化前后合法性检查，后端使用 Clang 的 O0 机器码生成与链接流程。

## 2. 分析和变换

常量传播使用正向数据流迭代。状态记录可证明的 SSA 常量和未逃逸局部栈槽常量，在可执行前驱汇合时取一致事实的交集。phi 按实际可执行前驱求值，循环回边参与迭代，直到状态和边集合稳定。

已知整数运算和比较在检查安全性后折叠。常量条件改为直接跳转，随后从入口遍历可达块，删除不可达块并修复 phi。副作用分析显式分类 I/O、堆写入、分配失败、运行时错误和可能不终止的行为，再沿调用图传播。

死代码消除以可观察效果和控制流指令为根，反向标记值依赖与活跃局部栈槽，删除未使用计算和局部写入。合并单前驱基本块时同步修正 phi 前驱。上述步骤重复到 IR 稳定。

## 3. 优化前后实例

配套程序为 `examples/optimization/constant_branch.toy`。

```text
def main() -> int {
    var x: int = 2 + 3;
    var unused: int = 7 * 9;
    if (x == 5) { return x * 4; }
    else { print("unreachable"); return 1; }
}
```

原始 IR 包含局部存储、整数辅助调用、条件跳转和两个分支。优化后 main 的核心指令为 `ret i64 20`。专项测试确认函数体的 call、br、alloca、load 和 store 均被消除，退出码为 20，stdout 为空。对应 CFG 从带条件分支的多个基本块化为单个返回块。

可以分别使用 `--emit-llvm -O0/-O1` 和 `--emit-cfg -O0/-O1` 导出前后 IR 与 DOT 控制流图。完整命令见 [优化说明](../optimization.md)。

## 4. 语义保持

类型检查先于优化，不可达源分支里的非法类型仍编译报错。除零、整数溢出和最小整数取负保持运行时错误，即使结果未使用也保留。未知调用、分配及可能抛错的访问均保守处理。

循环和递归被标记为可能不终止，因此不能因调用结果无用而删除。浮点运行时运算保持保守。各类变换保持语言定义的输出、返回值、错误和其他外部效果。

## 5. 验证与复现

在课程依赖镜像 `compilerlab-frontend:test` 中从源码重新构建，运行以下入口。

```bash
LAB_SUBMISSION_TESTS=1 bash tests/in-image.sh
```

测试包含 O0 和 O1 各 29 个原生测试方法、前端 API/CLI，以及 9 个优化专项测试方法。专项测试逐字节比较退出码、stdout、stderr，并检查跨块相同常量汇合、动态短路的 phi、副作用传播、可能不终止调用保留、CFG 节点/边和 LLVM 工具只执行 verify。镜像中 CTest 5/5 全部通过，课程 grader 的自声明功能检查也通过。验证日志位于 `reports/owned-optimizations.log`。

## 6. 对照与边界

课程要求的自写分析/变换及前后 IR、CFG 导出均已接入正常编译入口。实现面向本项目生成的指令集合，对未知指令与调用保守保留。内存优化追踪未逃逸局部槽，浮点算术保持运行时调用，循环不变量外提留作后续扩展。

本次以行为差分和结构变化检验效果，性能数据需使用独立重复测量。现有线程数计时探针用于并行调度观察，不作为中端优化加速比。
